Extension navigateur (recommandé)

Le blocage système (hosts + pare-feu) couvre tout, mais une extension bloque directement dans le navigateur — plus fiable, insensible aux résolveurs DNS alternatifs, et affiche un écran de pause au lieu d'une erreur de connexion.

  1. Clique "Ouvrir le dossier de l'extension" ci-dessous.
  2. Dans Vivaldi, va sur vivaldi://extensions
  3. Active "Mode développeur" (en haut à droite)
  4. Clique "Charger l'extension non empaquetée" et sélectionne le dossier ouvert
